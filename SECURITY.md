# Política de seguridad

## Versiones soportadas

La versión estable más reciente recibe correcciones de seguridad. Las versiones anteriores pueden dejar de recibir soporte al publicarse una nueva versión menor o mayor.

## Reportar una vulnerabilidad

No publiques vulnerabilidades explotables en un issue. Utiliza **Security → Report a vulnerability** en GitHub para enviar un reporte privado al mantenedor.

Incluye, cuando sea posible:

- versión y sistema operativo;
- impacto y superficie afectada;
- pasos mínimos para reproducirla;
- prueba de concepto sin datos privados;
- mitigación sugerida.

El mantenedor intentará confirmar la recepción en siete días y coordinar una corrección antes de la divulgación pública. No se garantizan recompensas económicas.
