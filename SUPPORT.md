# Soporte

- Para errores reproducibles, abre un [reporte de bug](https://github.com/RaulLzn/pliego/issues/new?template=bug_report.yml).
- Para propuestas, utiliza la [solicitud de funcionalidad](https://github.com/RaulLzn/pliego/issues/new?template=feature_request.yml).
- Para preguntas generales, utiliza [GitHub Discussions](https://github.com/RaulLzn/pliego/discussions) cuando esté disponible.
- Para vulnerabilidades, sigue [SECURITY.md](SECURITY.md) y no abras un issue público.

Incluye siempre versión de Pliego, sistema operativo y pasos para reproducir el problema. Nunca adjuntes documentos privados sin eliminar primero su contenido sensible.
